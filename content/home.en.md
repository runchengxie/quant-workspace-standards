## How the pieces fit

Standards define stable constraints. Playbooks turn repeated tasks into observable workflows. The dated talk preserves the speaker's experiences and interpretations.

The maintenance sequence is code → documentation and tests → closeout. Run only the workflow you need. The common delivery protocol is worktree → PR → checks → merge → task-owned cleanup, subject to existing authorization and repository controls.

## Scope

These are practices from one developer's projects, not a claim that every team needs the same architecture. Project documentation and Skill instructions use English as canonical; Chinese prompts localize the same requirements. The Chinese talk is original commentary.
